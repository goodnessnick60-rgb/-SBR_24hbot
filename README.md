# 📝 Telegram Text Summarizer Bot

A Telegram bot that summarizes long texts, articles, and messages using free AI without any API keys.

## 🚀 Features

- Summarize any text by replying to a message with `/summarize`
- Automatic summarization of forwarded messages
- No API keys required
- Free and open source
- Hosted on Railway

## 🛠️ Commands

- `/start` - Welcome message
- `/help` - Help guide
- `/about` - About the bot
- `/summarize` - Summarize text (reply to a message or send text)
